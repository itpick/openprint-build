# Offline RansomLeak SCORM conversion

Fully offline, iframe-free conversions of the RansomLeak open-source security
awareness SCORM packages (CC BY-NC 4.0). Generated by
`tools/convert-ransomleak-offline.sh`.

## Why

The shipped packages are thin shells: `scormdriver/indexAPI.html` iframes a
player hosted on `free-content-distribution.ransomleak.com` and fetches the
exercise content at runtime via `POST /scorm/launch`. They need network
access despite being called "SCORM packages".

## What the conversion does

Per course (`courses/<slug>/`):

- `exercises.json` — the course payload in the player's wire format:
  `base64(encodeURIComponent(JSON))` (the player's `Az()` parser expects this)
- `exercises.decoded.json` — human-readable copy for diffs
- `index.html` — flat page, no iframe:
  1. **network lock**: cross-origin `fetch`/`XMLHttpRequest`/`WebSocket`/
     `sendBeacon` are rejected before the player loads
  2. **local SCORM driver**: the driver methods the player resolves from
     `window.parent` (GetStudentName, SetPassed, CommitData, ...) are
     implemented as localStorage-backed no-ops
  3. same globals the hosted shell sets (`IS_SCORM_REMOTE=false`, package id)
  4. exercises loaded from the local JSON, then the local player bundle
     imported

Shared (once, not per course):

- `public/player/assets/` — player bundle: `index.js`, lazy chunks, 3D room
  models (glTF + KTX2), sounds
- `public/player/fonts/`, `public/draco/`, `public/basis/` — fonts and
  WASM decoders the player fetches same-origin when not remote
- `os/desktop`, `os/mobile` + `public/os/` — simulated in-scenario OS
  shells (the fake Windows desktop / phone screens)

## Verified offline

A headless-Chromium netlog capture of a course run shows **zero page
requests to any external host** — every request is same-origin (54 local
URLs across player chunks, models, audio, fonts, decoders, OS shells).
Fictional intranet URLs inside scenarios (`edr.stormveildata.com`,
`internal.healthfirst.com`, ...) exist only inside the simulated browser
widget and have no DNS records.
